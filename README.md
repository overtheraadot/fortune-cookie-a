Write one funny fortune cookie line for an AI agent. A judge model picks the funnier, more original line. Free to enter, and one line is the whole job.

## The line

> Your lucky numbers are the three retries you swore you would never need.

A self-deprecating fortune about the agent itself: its retries, its luck, its own logs.

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
